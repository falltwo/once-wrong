# 同版本多檔合成範例

這三份 CSV 均為原創合成資料，可一起作為 `life_filing_v1` 的一個版本上傳。它們展示同一家公司、同一保單的承保退保日期與給付發生日期匹配，以及無保單號碼的填報對象檔。

此 CSV 介面保存各檔原始 bytes、SHA-256、欄名與文字值；它不是官方定長申報檔。額外官方欄位可以保留，但目前只執行既有 11 條承保規則、給付發生日期 D1001，以及已核對條件的承保／給付保單與事故日期匹配。完整單檔規則、其他給付類別勾稽及填報對象規則仍明列未評估，這組範例不會取得正式確認資格。

給付日期欄沿用填報手冊的「發生日期」；介面也接受規則手冊使用的「事故日期」或「死亡完全失能日期」，同一檔只能選一個名稱，原始欄名不會被改寫。給付紀錄主鍵只有「給付類別、公司代號、保單編號、保單編號序號」，不把日期誤加進主鍵。

範例刪掉某個檔案時，缺少的規則會列為未評估。若要明確表示無給付資料，可提供只有合法標頭的 `claims.csv`；系統會區分「已提供空檔」與「未提供檔案」。同一版本每個檔種最多一份、每檔最多 1,000 筆及 2 MiB，不能混用公司或填報年度。
