## 預計怎麼做

- 用規則檢查報表，標出錯誤與版本間的差異。
- 讓 AI 用白話解釋錯誤、提出修正建議；建議要先通過規則重驗，資料仍由人修改。
- 提醒重複未通過的規則，留下每次檢核紀錄，最後由人確認送出。

目前還在建立原型，沒有可執行的系統或實測成績。之後會用同一批模擬報表，比較純規則、純 AI 和規則加 AI 的處理結果。
